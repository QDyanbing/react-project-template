# React 快速模板项目任务清单

## 1. 技术选型

### 1.1 基础环境

- [x] 选择 Node.js 版本。
- [x] 选择包管理器：Utoo（`ut`）、pnpm、npm、yarn 或 bun。
- [x] 确定依赖版本锁定和升级策略：不提交锁文件，干净环境按 `package.json` 的 `^` 范围解析。
- [x] 确定是否需要 Node 版本管理文件：使用 Volta，不增加 `.nvmrc`。

### 1.2 React 基础方案

- [x] 选择 React 版本。
- [x] 选择 JavaScript 或 TypeScript。
- [x] 确定 TypeScript 严格程度。
- [x] 确定是否启用 React Compiler。

### 1.3 工程构建

- [x] 对比 Webpack、Vite、Rspack 和 `@utoo/pack`。
- [x] 选择构建工具。

### 1.4 路由

- [x] 对比 React Router、TanStack Router 等方案。
- [x] 确定路由声明方式。
- [x] 确定路由模式。
- [x] 确定路由懒加载方案。

### 1.5 UI 与样式

- [x] 确定是否内置 UI 组件库。
- [x] 对比 Ant Design、MUI、Arco Design、shadcn/ui 等方案。
- [x] 对比 Less、SCSS、CSS Modules、Tailwind CSS 和 CSS-in-JS，并选择默认样式方案。
- [x] 确定主题和暗色模式方案：保留主题入口，不预置暗色切换。
- [x] 确定图标方案。
- [x] 确定全局样式、局部样式和设计变量的边界。

### 1.6 状态管理

- [x] 确定是否内置状态管理库。
- [x] 对比 Zustand、Redux Toolkit、Jotai、Valtio 等方案。

### 1.7 请求与接口

- [x] 选择原生 Fetch、Axios、ofetch、Ky 或其他请求方案。
- [x] 确定原生 Fetch 的统一封装边界。
- [x] 确定认证信息携带方式。
- [x] 确定接口错误的统一数据结构。
- [x] 确定取消请求、超时、重试和重复请求处理方式：取消使用 `AbortSignal`；不默认超时、重试和刷新 Token。
- [x] 确定接口 TypeScript 类型来源：手写 `src/services/typing*.d.ts`。
- [ ] 确定是否进行运行时数据校验。
- [x] 确定服务端数据缓存和同步方案：查询走 Zustand Store。
- [ ] 确定上传和下载方案。

### 1.8 代码规范

- [x] 选择代码格式化方案。

- [x] 确定 import 排序方案。
- [x] 确定 CSS 检查方案。
- [x] 确定文件、目录、组件、Hook 和类型的命名规范。
- [x] 确定 Git hooks 和暂存文件检查方案。
- [x] 确定提交信息规范。

### 1.9 工具库

- [x] 选择日期时间库。

- [ ] 确定是否需要运行时 Schema 库。
- [x] 确定是否需要国际化库。

### 1.10 测试

- [x] 确定需要哪些测试层级。
- [x] 选择单元测试框架。

- [x] 选择 E2E 测试框架。
- [x] 确定覆盖率要求。
- [x] 确定测试文件目录和命名方式。

### 1.11 工程能力

### 1.12 CI/CD

- [x] 选择 CI 平台：GitHub Actions。

- [ ] 确定部署环境和部署方式。
- [x] 确定多环境配置注入方式：构建时注入 `VITE_API_BASE_URL`。
- [ ] 确定版本号、Tag 和 Release 方案。
